# 恢复与安全

本板块记录经过准确板型资料确认并实际验证的备份、Maskrom/Loader/Recovery 入口和恢复流程。在开始烧录、分区或擦除前，必须先阅读本板块并确认：

- 目标设备身份无歧义；
- 电源、电压和线材符合板卡要求；
- 重要数据已有备份；
- 有经过验证的恢复入口和可用镜像；
- 操作命令、影响范围及中断风险已理解。

当前板型和恢复方式尚未确认，因此这里不提供通用 RK3588 接线或烧录步骤。

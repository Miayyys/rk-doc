# 恢复与安全

本板块记录经过准确板型资料确认并实际验证的备份、Maskrom/Loader/Recovery 入口和恢复流程。在开始烧录、分区或擦除前，必须先阅读本板块并确认：

- 目标设备身份无歧义；
- 电源、电压和线材符合板卡要求；
- 重要数据已有备份；
- 有经过验证的恢复入口和可用镜像；
- 操作命令、影响范围及中断风险已理解。

当前板型的通用烧录/恢复流程仍未确认，因此这里不提供通用 RK3588 接线或烧录步骤；下方仅记录已核对的具体备份与回退入口。

## 当前备份基线

- 已导出当前 R1 eMMC 的在线块级快照；源/目标长度均为 30924603392 字节，镜像与 `.sha256` 副文件已通过 `sha256sum -c`。证据与一致性边界见[EXP-20260807-002](../experiment/exp-20260807-002-boot-linux-via-debug-uart.md)。该记录不是已验证的烧录或恢复流程。

## 已验证的 p3 回退入口

- 完整 p3 原始备份主机源文件为 `build/local/r1-20260816/r1-boot-p3.img`，板端复制为 `/userdata/lzamp/recovery/r1-boot-p3-original.img`；均为 67108864 B，SHA-256 `e983740d4df29d51fa58dea9d504d536b87c8b205935ec2ceb8d64e679cd833b`。板端副本已从 U-Boot `mmc 0:8` 载入 RAM，进入 Linux `5.10.110` 且 `eth0` IPv4 正常；这只证明该具体 RAM 回退入口，不等于已验证通用恢复或写回流程。详见[6.12 LZAMP 实验步骤 16](../experiment/exp-20260902-002-lzamp-rockchip-6-12-evb4-booti.md)。
